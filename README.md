# Daily Commit

A simple daily commit streak tracker. Update one number in the code, commit your change, and keep track of your progress.

## How to use

1. Open `index.html` in your browser.
2. In `index.html`, find `const DAILY_NUMBER = 1;` and change `1` to a new number.
3. Save the file and commit your change to GitHub.
4. Check in on the page to record the day and update your streak.

The date updates automatically from your device. Check-in history is saved in your browser on this device only; it is not synced to GitHub.

## Project files

- `index.html` — page structure, daily number, and tracker behavior.
- `style.css` — page styling and responsive layout.
